全量数据库回归之后，仅调整了原生 Facebook 评论私信请求路径及对应合同断言、两处 HTML pattern 的连字符转义、浏览器用例的导航等待；后续合同、类型、lint、构建和相关浏览器用例分别重验，未修改数据库业务逻辑。旧站内咨询用例第一次因 45 秒总时限失败，单独复跑通过；旧运行详情用例过早点击跳转前页面的同名按钮，加入目标页面等待后复跑。保留这些首次失败信息，避免只报告最后一次成功。

最终合并结果：26 单元 + 81 合同 + 272 数据库 + 23 个不同页面用例（含定向复跑）+ 15 执行器用例，共 **417 项测试通过**。执行器用例覆盖 Agent/guardian 退出、未知结果、重复报告及上下文隔离。[检查点](evidence/acquisition-checkpoint.json) 记录每次检查时间、源码变化及各页面用例来自哪次运行；源码变动后未重跑的整套数据库检查明确保留差异，不伪称相同版本。
