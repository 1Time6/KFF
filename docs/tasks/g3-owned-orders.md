# TASK-090/093：独立订单合同与商品快照

基线 `4fba862`。依据用户独立主数据决定 ADR-017、规划 7.7、TASK-090/093、ACC-01/27/55/66，实现 KFF 自有商品、版本、订单预览与不可变订单快照。

允许修改合同、数据库新增迁移、业务服务、订单/商品工作台、API 和相关验证。原规划及其他站点不变。

商品的价格币种、精度来源、交付范围及条款显式登记；版本不可变，管理员启用后才可下单。订单由有权限的品牌成员为已有客户创建，先预览固定商品版本和整数金额再确认；变价或停用使旧预览失效，历史订单保持原快照。客户、可选来源会话和商品必须同品牌且互相关联。金额以最小单位整数字符串传输与计算，多项订单只能使用同一币种和精度。

本阶段只保存待核实订单或取消未接入支付的订单，没有手工标记支付成功的接口，不把成交阶段、成功页或订单创建当作已核实收入。支付接入、退款、交付和公共结账继续按后续任务实现。

验证包含跨品牌/跨客户、商品版本与停用、不可变订单、重复确认、并发、过期预览、数量和金额边界、币种精度冲突，以及浏览器预览/确认/变价/取消流程。只使用明确合成数据，不请求真实款项。

回滚保留已应用迁移、订单和历史版本；停止本项目服务后可回退代码，结构变更使用新迁移。

本次检查：新增 2 项输入合同、9 项隔离数据库与 1 项浏览器流程，全部回归共 258 项测试、9 类检查通过，覆盖 154 个源码/配置文件。检查点源码摘要 `c1c59021e8d224ac5e194725279dcd7dfd35272f51ade8a0899b567bf429dd18`，详见 `docs/evidence/g1-local-checkpoint.json`。生产构建在本地独立端口核对商品启用、精确报价、订单重复确认与取消。

修正并验证了不可变币种/预览记录的锁与权限关系：币种表保持只读，预览消费者使用事务级锁串行确认，不为锁记录而授予 UPDATE。浏览器校验修正了 SKU 的 HTML 正则转义，并核对手机尺寸布局。
