# TASK-061 单槽费用台账子范围

基线：`7b5c660`，101 项本地测试通过。按第 28 节的条件依赖，先实现可供 E2 复用的最小费用台账，不等待采集、批次或第二个平台。

内容：按品牌/币种的显式预算与记账精度；行动级费用预占；未知保留待核账；有明确账单依据的人工结算、零费用释放与差异调整；不可变事件及幂等请求；与既有试验次数和费用上限共同检查。原试验次数不因费用释放而退回。真实外部账单查询、批次拆分、多品牌公平调度、自动换汇及订单资金处理不计入此子范围。

原则：未知金额不是零；实际费用可以高于估算并如实记录，预算不足时拒绝新预占。不同币种分别汇总，精度由明确规则提供，不默认全部两位小数。过去的试验预占迁入待核账记录，不编造实际费用。

允许：新增合同、核心费用服务、迁移和作用域 API，试验预占内核接入、工作台管理和隔离数据库测试。没有支付、采购或真实 API 调用。继续采用先核对未完成范围、再保存代码检查点的方式。

验证：并发预算不能超占，同事件重复不重复记账，未知仍占用，释放不退试验次数，币种隔离、差异调整、超估算记录和过期版本拒绝。回退保留费用与未知事件；只通过新增迁移改变已应用结构。

实际代码：`packages/contracts/src/cost.ts`、`packages/core/src/costs.ts`、`20260911190913_g2_cost_ledger.sql`、作用域 API 和能力页的 `cost-ledger.tsx`。继续执行时重新核对预算，即使该动作已有预占也不能在总预算超额后继续。当前迁移应用到开发库时没有旧试验预占实样，其真实升级验收仍保留；不存在假定的实际费用。
