# TASK-037 人工裁定子范围

基线：`99f9fb5`，115 项本地测试。遵循规划第 9.1、9.2 节，保留 `NEEDS_HUMAN` 为自动状态机的停止点，人工后续处理写入显式、不可变事件。

本次新增按原动作快照和裁定版本核对的管理员入口。确认成功需要匹配的远端对象、账号、内容和原提交关联；确认失败需要平台明确的最终拒绝或取消依据。“没有查到”只允许保留待人工。明确标注证据来自人工复核，不能借此获得真实平台能力晋升或主页身份的机器核验资格。

最终裁定要求旧命令全部终止并确认关闭，写动作确认成功还要求已记录提交意图。幂等请求和并发版本控制防止互相覆盖。裁定不自动重发、返还试验次数、结算费用或解除环境隔离。真实 Graph 只读对账命令和实际平台试验仍保留未完成状态。

允许新增合同、迁移、核心服务、详情接口/表单、隔离数据库和本地浏览器样本。没有真实平台调用。验证包括证据不足、错误账号/内容、缺提交意图、缺关闭确认、竞态、重放、不可变事件及跨品牌拒绝。
