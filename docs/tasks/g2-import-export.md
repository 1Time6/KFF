# TASK-051 Excel/CSV 导入导出

基线：`63a509f`，按项目规划 7.2、22 节及 ACC-16 实施。先实现并验证代码，真实 Facebook 读取按用户要求另行验证。

交付：上传文件、工作表与字段映射、逐行预览、错误及重复明细、明确确认有效行、人工来源观察入库、品牌和来源字段限制下的 CSV/XLSX 导出。人工导入复用采集观察与身份表，不创建客户主数据，不授予联系资格。

原文件 8 MiB、每表 1000 数据行、32 列、最多 5 表；CSV 显式选择 UTF-8/GB18030/UTF-16LE。独立受限解析进程校验容器、解压大小、行列和时限。映射拒绝数值 ID、公式单元格和不兼容字段类型。CSV 导出使用明确标记的文本转义格式，XLSX 使用文本类型；字段状态单列，区分空、未返回、隐藏和零。

确认绑定不可变文件、映射预览摘要及排除数量；并发或重复提交不得重复入库。同一人工来源按账号、命名空间和原始 ID 去重，观察追加版本。原文件访问可选上传者/管理员或当前品牌，原文件及数据保留期独立设置。

验收将覆盖独立 XLSX 样本、CSV 编码与换行、长 ID 和前导零、公式输入与导出、并发确认、跨品牌访问、字段限制、到期清理、浏览器完整流程及原有回归。真实平台来源、来源专有许可策略、备份副本删除及任务转换另有任务，不能由本次本地检查冒充通过。
