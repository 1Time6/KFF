# Excel / CSV 导入与查询导出

当前实现 `TASK-051` 的 CSV / `.xlsx` 文件流程。人工来源为 `MANUAL_IMPORT`，用途 `data_review`；其结果不会成为自动采集证据或联系许可。

## 上传、映射、确认

1. `POST /api/imports`：认证并校验同源后，使用 `application/octet-stream` 上传原始字节。`x-kff-import-metadata` 为 URI 编码 JSON，包含请求 UUID、品牌内账号、标题、文件名、格式、编码、人工来源命名空间、来源说明、处理依据、允许导出的字段、原文件访问范围和两种保留期。
2. `GET /api/imports` 返回最近 100 个文件的元数据。`GET /api/imports/:id` 提供上传者/管理员或获准品牌成员的工作表表头、最新预览和确认结果；原文件访问设定同样约束映射入口。
3. `POST /api/imports/:id/previews` 固定工作表、表头行、ID 列、字段列、可选状态列及 CSV 文本编码方式。保存逐行错误、文件内重复、已有同源对象版本和不可变摘要；原始行号从 1 开始，列号从 0 开始。
4. `POST /api/imports/:id/confirmations` 必须携带预览 UUID/摘要、准确的排除错误行数及 `confirm_valid_rows: true`。全部错误时不能确认；有效重复行追加观察并按身份去重。相同请求重放和相同文件/映射/来源语义的重复导入复用原结果。同源记录在预览后变化时要求重新预览。
5. `GET /api/imports/:id/original` 按原文件访问范围下载，在到期前可用；所有下载有审计，采用附件响应、禁止缓存与嗅探。

确认在同一 PostgreSQL 事务内写入采集查询、完成状态、页面证据、对象身份、观察、结果指针、确认凭据与审计。身份键为品牌、账号、`manual:<source_namespace>` 和字符串原始 ID，不能与合成自动采集来源混同。来源摘要绑定文件 SHA-256、映射、原始行号和内容。成功入库不会扩张用户确认的有效行集合。

## 输入边界

- 原文件最多 8 MiB；最多 5 表、每表最多 1000 数据行、32 列、单元格最多 5000 字符，表头可在前 20 行选择。
- CSV 明确选择 UTF-8、GB18030 或 UTF-16LE；解码错误停止，保留引号、逗号、换行和字符串 ID。数量字段单独验证为非负安全整数。
- XLSX 根据 Open XML 命名空间读取文本、数字、共享字符串及内联文本，兼容有/无命名空间前缀。数值 ID 一律报错；不猜测格式或还原已经丢失的精度。公式单元格、布尔/错误/其他不支持类型列为错误，不使用公式缓存结果。日期需提供明确 UTC 文本。
- ZIP 最多 2000 项，单项解压 8 MiB、合计 32 MiB，拒绝重复/非法路径、加密、宏、嵌入对象、ActiveX、外部链接和 DTD。不读取 URL、本地任意路径，不执行原文件内容。
- 解析为独立隐藏 Node 进程，堆限制 256 MiB、15 秒超时、最多两个同时解析，输出上限 16 MiB。子进程不继承数据库或平台凭据。这是资源与协议边界，未声称具备操作系统级恶意本机进程隔离。

## 导出与往返

`POST /api/collections/:id/exports`：`format` 为 `csv`/`xlsx`，`fields` 只能选查询中来源允许导出的字段。可提供精确 `result_ids`；不存在、跨查询或已到期的对象会拒绝整个选择。省略选择表示本查询全部有效结果，最多 1000 个去重对象。导出保存所选观察 ID、字段、文件摘要、来源覆盖及到期时间审计。

每个选定字段同时导出 `<field>__kind`，分别保留 `VALUE`、`NULL`、`NOT_RETURNED`、`HIDDEN`；空字符串与零不会混为缺失。辅助列包括来源类型、来源位置、观察 UUID、观察时间、到期时间、证据摘要、允许用途、查询 UUID、返回/去重数量及已知覆盖。未知来源总量保持空值。

XLSX 将 ID 和所有字符串作为文本写入，不创建公式。CSV 使用 UTF-8 BOM、完整引号与 CRLF；所有文本值前置单引号并以 `_kff_text_encoding=apostrophe-v1` 标记。回导时选择 `kff-apostrophe-v1`，验证逐行标记后只解码一次。单引号可能在直接打开 CSV 时显示；需要 Excel 原生文本类型时使用 XLSX。CSV 的引号本身并不能声明 Excel 单元格类型，因此不以普通 CSV 的双击显示宣称精度安全。

## 保留与权限范围

原文件和规范化数据分别设置 1–30 天期限。到期读取立即拒绝/隐藏，Worker 每分钟清理原文件字节、解析数据和预览行；采集观察沿用已有到期清理。摘要、配置和审计保留以解释历史。下载副本及备份由对应保留任务另行管理，本任务不声称清除所有副本。

表使用品牌 RLS 与复合外键，HTTP 入口额外执行角色和原文件访问规则。viewer 可读取获准结果及字段，但不能上传、映射或确认。具体真实来源的许可与字段策略需在来源接入任务中验证。
