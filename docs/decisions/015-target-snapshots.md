# ADR-015：精确选择绑定对象与观察版本

当前页、手选与全筛选在服务端显式区分。当前页携带所见结果页摘要，手选携带对象和观察 ID；服务端校验当前筛选及来源。全筛选只读取当次持久结果，不保存一个以后重新执行、可能扩大范围的查询表达式作为批准对象。

预览和快照保存原始字符串 ID、观察版本、证据摘要及所选字段副本。这样后续采集更新当前结果时，原固定选择仍能核对和导出原观察。副本有效期不晚于来源，接口即时隐藏过期内容，Worker 分批清理并审计。保留期不因再次保存或导出而延长。

请求锁与预览锁协调幂等保存。请求 ID 与预览均已有不同资源时，优先查找请求 ID，防止将旧请求重绑定到另一资源；同样修正人工导入确认的既有查询排序，并加入回归样本。

快照定义不可变，撤销状态按版本更新；共享读取与撤销使用数据库锁协调。预览/查询复合外键与品牌 RLS 保证关联隔离。保存明确核对纳入和排除数，不授予平台提交权限。具体动作、联系依据、退出及预算仍要由后续任务门槛复核。

本地验证覆盖三种范围、增量观察、筛选变化、过期、撤销、并发保存、请求冲突及浏览器操作。真实平台来源及结果到实际任务执行尚未验收。
