# ADR-017：KFF 独立拥有业务主数据

2026-09-12。用户在当前会话明确决定：

> 最轻的方案是完全独立。KFF 自己拥有客户、订单、聊天、数据

据此，KFF 自己管理客户身份、会话与消息、商品和订单、支付核验及交付记录；不导入或复用 EasternWisdom、Pearl 的数据库、客户、订单或接待系统。后续外部平台仅通过明确接口提供事件或执行能力，不成为 KFF 内部业务对象的另一套主数据。品牌、连接器与外部身份命名空间继续隔离，同名不会自动合并。

这是对规划 8.3、TASK-006/087/090 中“优先复用已有系统”的用户明确范围调整。原始规划及哈希保持不变，旧候选盘点作为历史证据保留。主数据选择阻塞已解除；其他资料、真实平台与设备验证缺口没有因此通过。

首条咨询入口采用规划 TASK-078 允许的 KFF 自有站内收件端点。访客由服务端签发独立会话，主动发来消息后才建客户；消息、事件、身份、会话和联系依据先持久化再确认。客户档案、阶段和负责人由有权限的品牌成员维护。数据入口与发送能力分别验收，人工回复仍须接入已有任务执行内核。

Facebook 仍为首个发布平台，真实 Facebook 测试按之前的用户指令后置。完整产品尚未交付，关机条件尚未满足。
