# ADR-016：显式时区规则与有限日历

使用固定的 `@js-temporal/polyfill@0.5.1`，运行环境 Node.js 24.14.0 尚未提供原生 Temporal。参照 [Temporal ZonedDateTime 官方说明](https://tc39.es/proposal-temporal/docs/zoneddatetime.html) 的时区与歧义处理接口，分别计算较早和较晚候选，再按显式重复/缺失配置选取；不假设偏移总是整小时，也不以固定 UTC 间隔代替当地每日规则。实现及版本来源见 [Temporal polyfill 官方仓库](https://github.com/js-temporal/temporal-polyfill)。

将最多 366 天的规则编译成不可变日历，预览后保存。重复时刻的两次分别有稳定键；跳过的缺失时刻保留说明但没有虚构提交时间。保存 ICU/IANA 数据版本，未来环境更新时阻止静默使用过时解释，需新版本重新核对。

先提供时点准备，复用现有 Worker 和数据库事务。事务一次处理本次全部已到期集合，限量补准备之外的记录明确跳过并推进游标，避免每轮循环重新补出上限。被最迟期限拒绝的时点不占用释放间隔。有限规则既控制求值与响应规模，也使一次恢复有确定边界。

准备记录与实际业务动作分开。后续 TASK-060 必须绑定精确账号/目标、固定内容、批准、预算和停止状态；不能仅凭 `READY_FOR_TASK` 提交。停止和版本替换当前只取消尚未绑定业务动作的准备记录，实际在途边界仍由共同执行内核承担。未连接真实账号，不计为完整 ACC-34/68 或真实定时执行通过。
