## 1. F1 修复（范围：`apps/agent/src/guardian.ts` + 一个新测试文件）

- 根因：`settle` 同步执行，子进程被 kill 后 `exit` 立即写 `recordNoProgress`，此时
  `await terminateProcessTree(...)` 的判决尚未赋值 → 落盘 fallback UNKNOWN，真实 DEAD 判决被丢弃。
- 修复：增加 `terminationInFlight` / `terminalEventObserved` 两个状态；
  - forced termination 开始前置 in-flight；
  - in-flight 期间收到 exit/close/error 只记录 terminal event，不 settle；
  - verdict 落定后由其 continuation settle，真实判决进入 evidence；
  - 真实 closure 仍优先；TIMEOUT/UNAVAILABLE 仍诚实 UNKNOWN；
  - `if (settled) return` 防止 late continuation 产生副作用；settle-once 不变。
- 未修改 `process-tree / protocol / contracts / core`。唯一测试注入缝为
  `runGuardian(..., deps?: { terminate? })`，默认走真实 `terminateProcessTree`，生产调用不变。
