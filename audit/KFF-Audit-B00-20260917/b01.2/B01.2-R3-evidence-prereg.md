## 1. 预登记预测（force=10000 矩阵）

### P1 —— §7：生产 default 应当**减少**上游终止类失败
- **依据**：`force=10000` ⇒ `deadlineMs=9000`，`killReserve=min(floor(9000/3),1500)=1500`，
  枚举上限 `9000−1500=7500ms`；而此前失败档 `force=5000` 枚举上限仅 **2667ms**。
  §4.2 实测 taskkill 在 2.0× 已达 max 1143ms，逼近 1333ms 保底。
- **预测**：同一负载下，`force=10000` 的 `:286/:291`（poll / termination 断言）失败率
  **低于**此前 `force=5000` 的观测。
- **会证伪它的**：2.0× 行在此前的失败形态上**照样失败**，或失败率相当。

### P2 —— §7：3.0× 仍是边界，但**失败形态可能改变**
- **依据**：枚举上限从 2667 提到 7500，`TIMEOUT` 更不容易发生；`KILL_RESERVE_MAX_MS=1500` 在
  `force=10000` 下**是**约束方（`force=5000` 下不是，见 §7.1 表）。
- **预测**：3.0× 若失败，更可能落在 **别处**（用例 90s 超时 / poll 10s 超时 / flush），
  而**不一定**复现"守护进程仍活着"。
- **会证伪它的**：3.0× 仍以 `:286` poll 失败、且落盘的 `termination` 显示 kill 饥饿。

### P3 —— §8：flush=false 的机制是**资源租约过期**（当前最强假设）
- **依据**：stall 用例不续租（§0 末行），而 `acceptReport → validateLeases` 要求资源租约未过期；
  浏览器启动含在租约窗口内。
- **预测**：若能抓到一次 refusal，诊断里应满足**全部**：
  1. `calls` 末项为 `{"endpoint":"action-reports","error":"LEASE_STALE"}`
  2. `leases[].expires_at < leases[].now`（至少一条）
  3. `command.state='CLAIMED'` 且 `command.quiesced_at IS NULL`
  4. `journal.quarantined === true`
- **会证伪它的**：`calls` 末项是 `status:`（⇒ `:77` 分支）或为空（⇒ `:68`），
  或 `error` 是 `VERSION_CONFLICT`，或 lease 未过期而仍拒绝。

### P4 —— §8：`force=10000` 会**提高**抓到 flush refusal 的概率
- **依据**：P1 成立时上游失败减少 ⇒ **更多运行能走到 flush**；而 flush 的绝对时刻不变。
  此前 `force=5000` 的 8 次 2.0× 尝试全部死在 flush 上游，是"上游失败遮蔽了下游失败"。
- **预测**：2.0× 行（乃至 1.5×）若出现红测，**落在 flush 的比例应高于**此前 8 次尝试的 0/3。
- **会证伪它的**：2.0× 全绿，或红测仍全部落在 flush 上游。

### P5 —— §8：若 P3 成立，则**不是生产缺陷**，而是用例保真度缺口
- **依据**：生产 `main.ts` 一直在续租；只有这两个用例不续租。
- **预测**：`force=10000` 下**不应**出现"租约已过期但上游全绿"以外的其它 flush 拒绝原因。
- **会证伪它的**：抓到一条 `calls=[status:CLAIMED, action-reports, error=VERSION_CONFLICT]`，
  或租约**未**过期却仍被拒 —— 那就说明还有第二条与续租无关的机制。

## 4. 本轮诊断件的**不可影响结果**论证（可复核）

`withTreeDiagnostics` / `flushObserved` 只在**断言已经抛出之后**才动作，并**原样 rethrow 原错误**：

- `withTreeDiagnostics`：`try { return await body(); } catch (error) { <dump>; throw error; }`

  无 `this`；包装体只做一次数组 push 后原样 `return`/`throw`，不重试、不延迟、不吞异常。
